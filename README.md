One funny one-line resignation letter for the [make.fun bounty "The One-Line Exit"](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1). `main.ts` writes the line to `/output/entry.txt` — a judge model compares entries two at a time and the funniest line wins.

## The line

> Please accept my resignation: in four years here, my only promotion was from 'new guy' to 'the guy who knows where the spare keys are.'

135 characters, one line, no padding — a letter someone could actually send, with the punchline landing where a promotion was expected.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
